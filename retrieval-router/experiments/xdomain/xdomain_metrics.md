> 训练：Qwen3-0.6B + LoRA，金融三域（FinQA/ConvFinQA/VQAonBD），λ=0.1 与 λ=0 各一个
> 测试：源域测试 + 三个完全留出语料库（TAT-DQA / Wiki-SS / ArxivQA）
> 所有指标由原始 `<arm>_ndcg` 重算，不使用预测文件中的 reward 派生列

## 2. 三条核心观察

### 观察 1：跨域退化真实且严重，但不是单纯的"域漂移"

Router nDCG 从源域 0.847 降至目标域 0.444–0.679，Quality Regret 是源域的 2.2–3.4 倍，灾难性掉零率从 2% 飙升至 13–27%。但更关键的是：**λ=0.1 的 Router 在全部 4 个测试集上都输给"永远选 MR"这一最简单固定策略**（源域 0.847 vs 0.857，arxivqa 0.444 vs 0.630）。这说明退化不只是跨域问题，训练目标本身就在系统性地选错臂。

### 观察 2：λ=0.1 的延迟权重是 MD 偏差的根因（可复现、可修复）

在训练集上，MR 是 nDCG 最优臂的比例为 **77.0%**，但经过 λ=0.1 的 reward = 0.9·nDCG + 0.1·(1−normalized_latency) 变换后，MR 是 reward 最优的比例骤降至 **7.5%**。原因：MR 延迟 1.23s 而 BM25 仅 0.02s、MD 0.37s，延迟归一化项彻底淹没了 nDCG 优势。结果 Router 学到偏好快臂（MD 选择率 58%，oracle 仅 13%），回避高质量臂 MR。

**验证**：用 λ=0（纯 nDCG reward）重训后，MR 选择率在源域/tatdqa/arxivqa 上从 23%/27%/23% 提升至 53%/62%/70%，接近 oracle 分布；nDCG 分别提升 +0.015 / +0.010 / **+0.115**。Dense→Rerank 误路由率从 50–61% 降至 21–31%。

### 观察 3：Wiki-SS 暴露了真正的 Query-only 信息瓶颈

λ=0 在 tatdqa/arxivqa 上基本修复了偏差，但在 wiki-ss 上反而恶化（MD 选择率 66%→85%，oracle 仅 23%）。Wiki-SS 的特点是：
- 最优臂分布不同：TR（0.774）和 BM25（0.745）反超 MR（0.732）
- Query 是短事实型（"where was the creature from the black lagoon filmed"），与金融训练域的长表格查询分布差异极大
- Router 在金融域学到的"哪些查询特征预示 MR 有效"无法迁移，退化为默认选 MD

坏例显示：wiki-ss 中大量简单事实查询被路由到 MD（nDCG=0），而 BM25/TR/MR 均为 1.0。Router 不是"不知道该选哪个文本臂"，而是根本没意识到这类查询不需要多模态检索。
