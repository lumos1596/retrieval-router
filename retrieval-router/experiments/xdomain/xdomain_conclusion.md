# 跨语料泛化实验结论

## 是否出现可复现的跨库退化？—— 是，且由两层机制叠加

**第一层（训练目标缺陷，可修复）：** λ=0.1 的延迟权重将 MR（nDCG 最优 77%）压成 reward 最优仅 7.5%，导致 Router 系统性偏好快臂 MD、回避高质量臂 MR。此缺陷在源域即存在（Router 0.847 < 永远-MR 0.857），跨域后因目标域 oracle 更高而放大。**已验证可被 λ=0 修复**（arxivqa nDCG +0.115）。

**第二层（Query-only 信息瓶颈，结构性）：** 即使修复目标偏差，Router 在 wiki-ss 上仍选 MD 85%（oracle 23%），因为金融域学到的查询特征无法迁移到短事实型查询。这是真正的跨域泛化失败。

## 是否值得进入语料库画像研究？—— 有条件地值得，但需先排除更简单的解释

### 支持继续的证据
1. **三个目标域全部退化**，且 tatdqa（同领域未见语料）也退化 0.23 regret，说明不仅是领域差异，语料库本身的检索能力分布变化也起作用。
2. **各语料库的最优臂分布确实不同**：金融域 MR 绝对最优（0.86），wiki-ss 上 TR(0.77)/BM25(0.74) 反超 MR(0.73)，arxivqa 上 MR(0.63) 领先但 MD 暴跌至 0.42。语料库画像（哪个臂在哪个库更强）是真实存在的信号。
3. **Dense→Rerank 误路由是全局最大错误源**（50–61%），且前期机制研究已证明其方向由候选集结构决定——这天然需要语料库/候选集侧信息，Query-only 不够。

### 必须先排除的更简单解释
1. **λ 修正后还剩多少退化？** λ=0 已消除 source/tatdqa/arxivqa 的大部分偏差。剩余差距中，有多少是"语料库画像缺失"，有多少是"Query-only 本身无法判断 rerank 增益"（候选集决定）？二者需要分解。
2. **永远选 MR 已经很强**：在 tatdqa/arxivqa 上永远-MR 达到 0.656/0.630，远超 λ=0.1 Router。一个语料库级的"默认臂先验"（金融/论文→MR，知识→TR/BM25）可能已经能拿到大部分收益，未必需要复杂的能力画像。
3. **训练样本不足**：本轮训练只用 3 个金融数据集（15.5K 条），远少于原论文 11 域 68K 条。部分退化可能源于训练覆盖不足而非 Query-only 的本质局限。

## 建议的下一步（按成本递增）

### 步骤 A：验证"语料库级臂先验"的上界（已完成，零训练）

对每个目标域取全局最优固定臂：
- tatdqa → MR: 0.656
- wiki-ss → TR: 0.774
- arxivqa → MR: 0.630

加权平均 = **0.733**，对比：
- λ=0.1 Router: 0.669 → 语料库先验上界 **+0.064**
- λ=0 Router: 0.689 → 语料库先验上界 **+0.044**

**结论**：语料库身份确实携带增量信息。收益主要来自 wiki-ss（最优臂是 TR/BM25 而非 MR，先验 +0.108）；在 MR 最优的 tatdqa/arxivqa 上，λ=0 Router 已能选 MR，先验收益较小（+0.035/+0.071）。这说明"知道在哪个语料库"主要价值在于切换最优臂族，而非精细的逐 Query 路由。

### 步骤 B：候选集感知的 Rerank Gate（低成本探测，核心创新方向）
基于前期机制结论（rerank 增益由候选集结构决定），设计两阶段级联：
1. 先跑最便宜的 Dense 臂（MD 或 TD，由 Query 决定模态）
2. 用返回的 Top-K 候选特征（近重复密度、Top-1/2 分差、数字 token 覆盖率、表格/OCR 占比）决定是否升级到 Rerank
3. 不重训 Router，只加一个轻量 Gate

这直接针对最大错误源（Dense→Rerank 误路由），且不需要语料库标签——候选特征本身就是"语料库能力画像"的廉价代理。

### 步骤 C：Corpus-aware Router（仅当 A、B 证明有空间时）
在 Router 输入中拼接语料库级统计特征（各臂历史 nDCG 分布、页面类型分布），或用 mixture-of-experts 按语料库路由。**注意**：这需要目标语料库的少量标注来构建画像，不能算作零样本。

## 最终判断

> **跨域退化可复现，且存在两层机制。** 第一层（λ 延迟偏差）已被实验否定为"语料库问题"——它是训练目标 bug，修复后 3/4 域显著改善。第二层（wiki-ss 特征迁移失败）是真正的 Query-only 瓶颈。

**语料库画像的价值已通过上界验证**：语料库级臂先验（0.733）比 λ=0 Router（0.689）高 +0.044，且主要来自最优臂族切换（wiki-ss 的 TR vs 金融/论文的 MR）。但需注意：
- 这 +0.044 中，有多少可被"无需标签的语料库统计特征"拿到，有多少需要标注，尚未验证。
- 更大的剩余差距在 oracle（~0.89）与先验（0.733）之间，这是 Query-only 无法做逐 Query 精细路由的结构性损失，语料库画像未必能填补。

**建议优先级**：
1. **立即可做**：将训练目标从 λ=0.1 改为 λ=0（或更优的延迟归一化方式），这是零成本的质量提升。
2. **核心创新方向**：候选集感知的 Rerank Gate（步骤 B），直接攻击最大错误源（Dense→Rerank 误路由 50–61%），且候选特征天然编码了语料库能力差异。
3. **语料库画像**：可作为 Gate 的补充特征（语料库级臂先验 + 候选集特征），但不建议作为独立主线——先验上界仅 +0.044，单独投入 ROI 不高。
