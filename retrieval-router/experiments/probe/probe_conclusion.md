# 探针实验结论

## ① 全局能力先验有用吗？—— 有用，尤其在最优臂不同于MR的语料库

| 数据集 | Fixed-MR | Global(100) | 增量 | Best Fixed |
|---|---|---|---|---|
| tatdqa | 0.6554 | 0.6506 | -0.0048 | 0.6554 |
| wiki-ss | 0.7332 | 0.7685 | +0.0354 | 0.7752 |
| arxivqa | 0.6307 | 0.6307 | +0.0000 | 0.6307 |

- **wiki-ss**：Global 从 0.733→0.769（+0.036），因为该库最优臂是 TR 而非 MR，探针能正确识别。
- **tatdqa/arxivqa**：最优臂就是 MR，Global 与 Fixed-MR 接近（探针只是确认了 MR 最优）。
- 结论：**语料库级先验有价值**，主要价值是切换最优臂族，而非逐 Query 精细路由。

## ② Query级局部信息是否提供额外收益？—— 否，Local 未超过 Global

| 数据集 | Global(100) | Local(100) | Local−Global |
|---|---|---|---|
| tatdqa | 0.6506 | 0.6336 | -0.0170 |
| wiki-ss | 0.7685 | 0.7463 | -0.0223 |
| arxivqa | 0.6307 | 0.5926 | -0.0380 |

- Local 在全部 3 个语料库上均低于 Global（−0.017 至 −0.023）。
- 可能原因：探针量小（100条），近邻的最优臂噪声大；Query 嵌入相似不代表最优检索臂相似；平均化五维 nDCG 稀释了信号。
- 结论：**当前实现下 Query 级局部匹配无额外收益**，不支持"Query级能力指纹"作为主创新。

## ③ 哪些语料库/Query类型有效或失效？

- **有效**：wiki-ss 的全局先验（识别 TR/BM25 优于 MR）。
- **失效**：所有语料库的局部匹配；tatdqa/arxivqa 上 Global 与 Fixed-MR 无差异（因为 MR 本就是最优）。
- **共同瓶颈**：Local−Oracle 差距巨大（0.10–0.22），说明逐 Query 最优臂无法从相似探针的 nDCG 向量可靠推断。

## 总体判断

本轮属于方案定义的**弱信号**：Global 明显改善，但 Local 基本无额外收益。
建议：
1. 可将**语料库级臂先验**作为轻量特征加入路由（低成本、有收益）。
2. **不建议**继续投入"Query 级局部能力探针"方向——当前证据不支持其有独立于全局先验的增量价值。
3. 若要追求逐 Query 路由收益，应回到**候选集感知的 Rerank Gate**（直接利用检索结果特征，而非 Query 相似度），这是前期机制研究指出的更有希望的方向。
