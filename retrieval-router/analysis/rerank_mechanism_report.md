# Dense → Late-Interaction Rerank 机制验证报告（28 案例重放）

**问题**：同一 Query 的同一 Dense Top-100，经 MaxSim 晚交互 Rerank 后，nDCG@5 为何有时显著变差/变好？这种变化能否在重排前被候选集特征预判？
**设计约束**：不训练 Router、不做新网络、不做大规模消融；两臂共用同一 Top-100（MD→MR=Nomic Dense→ColNomic/ColQwen2.5 多向量；TD→TR=Linq→GTE-ModernColBERT）；Rerank 仅为 MaxSim 晚交互。28 案例（A 有害 8 / B 4 / C 有益 8 / D 4 / E 并列 4），SEED=20261016，清单见 `cases_28.csv`。配套数据：`rerank_case_details.csv`（104 列）、核实案例见 `rerank_casebook_verified.md`。

## 1. 复现对齐结果（先验收，再谈机制）

全部 28 案例共 50 次有需求的臂重放，Dense 37 次、Rerank 37 次（3 个纯文本案例不需要 MR）。

| 阶段 | 臂 | 精确对齐 | 不一致（已归因） |
|---|---|---|---|
| Dense | MD（25 例） | 20 | 5：4188 为 rank1/2 **精确同分**（Qdrant 存储序不可复现）；5626/2330/2544 边界相对分差 ≤2.1%；7082 为 1.2% 小分差翻转 |
| Dense | TD（12 例） | **12** | 0 |
| Rerank | TR（12 例） | 7 | 5：GT 对最强非 GT 页的相对分差全部 **≤1.0%**（4 例 ≤0.8%），属近平局簇内抖动 |
| Rerank | MR（25 例） | 10 | 4 例精确同分（近重复页向量相同）；2 例近平局簇（GT 分差 ≤0.15%）；**9 例决定性不一致**（见 §3） |

Dense 臂（尤其 TD 12/12）与"非边界区"TR 的精确对齐，验证了语料、qrels、uuid5 点 ID、平局规则、MaxSim、nDCG@5 口径全部正确（Qdrant `:memory:` exact 模式独立复核，排序与 numpy 一致）。

## 2. 已对齐案例上观察到的机制（8 正 1 负，均经页面图/原文人工核实）

**正增益（C/D，9 例对齐中 8 例为正增益，跨 5 个数据集、两臂一致）**：候选集中普遍存在多个**主题正确、版面/模板高度相似**的页面，Dense 全局向量对它们区分度低，MaxSim 靠细粒度 token 共现修正：
- **跨年年报同一张表**（2013：HCA 2017 报告页胜 2018 同编号页；697：MO 2017 页胜 2016 页）——年份 patch 与表格列精确对齐；
- **同实体同模板表单消歧**（5177：同一员工两张 SALARY ACTION 表，靠日期/数字 patch 选中 qrel 页）；
- **长多表页内的精确行标签**（4217："Restricted cash within other current assets"整行，胜主题相同但缺该行的两张近重复 reconciliation 页；2544："Operating Income"小标题页）；
- **稀有实体短语全词命中**（TR 45：KONE+elevators/escalators；343：公司×年份×auction rate securities 三交集；7082：角色页含 Carrie 双重线索）。

**负增益（A/B，严格对齐仅 1 例：2481）**：GT 是含 R&D 费用行（2019=355,015、2018=230,674）的经营费用正表；Rerank 顶上来的"无形资产"附注页同样有 2019/2018 数字表、**甚至也有一行 "Research and development"**（摊销费用 266/60）。区分正表与附注需要跨表头的全局语境，而 MaxSim 逐 token 取最大局部匹配，被标签+年份+数字密度的表层共现骗过。该翻转发生在 Top-5 边界 <0.5% 的近平局簇内（不是自信地选错）。

**并列（E）**：GT 在两臂均稳定第 1（735 四臂全 1；1962/7821/8396），候选无歧义，rerank 不改变顺序。

**特征侧的描述性佐证（label-free，n 小，仅描述）**：所有已对齐案例 Dense Top-10 都含近重复/同模板页（`near_dup_in_top10=1`），故"近重复密度"不区分方向；方向差异取决于判别线索是**局部行级标签/实体共现（正增益）**还是**整页语境（负增益）**。TR 正增益案例 rerank 第 1 页的 query token 覆盖率高于 dense 第 1 页（0.771 vs 0.684）；唯一 MR 负增益案例相反（0.538 vs 0.692），但其数字/年份覆盖率仍为 1.0——"数字命中"在两侧都高，不能单独作为有害信号。

## 3. 复现偏差：9 例 MR 决定性不一致（红线处理）

MR 有 9 例（2899、3341、4445、5372、5626、6027、7659、7959、8381）Dense 对齐、但官方 Rerank 与我们的重放在**非平局区**给出相反结果：我们的模型把 GT 放在距最强对手相对分差 1.2%–19% 的位置（如 2899：GT 23.01 vs 次高 20.77，官方却记 GT 第 2）。全库（2,758 页）重放排除"候选尾部缺失"。以下假说均已用证据排除（细节见附录 A）：Qdrant MaxSim 语义、token 归一化、候选边界、LoRA 未生效、图像/文本字节差异、transformers/colpali-engine/pylate 版本、适配器与基座权重历史、数据集 revision。**结论：官方 xlsx 的多模态晚交互列产生自某个未随仓库发布的上游状态（外部 Qdrant 多向量 collection 的实际索引向量/构建时软件环境不可得）；按实验计划第 4 节，这 9 例（及 4 例精确平局、2 例近平局）标记为复现偏差，不做任何算法层面的机制解释，也不参与增益方向统计。** 一个重要副作用：28 例中 A/B 组"Rerank 有害"的官方案例绝大多数落在这批不可复现样本上，因此**本次重放无法对"有害侧"给出超过 1 个核实案例的结论**；文本臂的 5 例偏差全部在 ≤1% 抖动区，不影响 TR 在决定性区间的机制结论。

## 4. 计划第 6 节结论（三选一之 (b)）

**重放支持的结论**：晚交互 Rerank 的增益/损害有可解释、可观察的候选集层面机制——它在"近重复/同模板页之间靠行级标签、年份、稀有实体共现做细粒度消歧"时稳定有益；在"多个候选共享全部表层线索、正确答案依赖整页/跨表头语境"时可能有害，且翻转集中在分数近平局簇内。**重放不支持**的结论：在 28 例上拟合并宣称任何可上线的 Gate——负增益侧仅 1 个可核实样本，单一 label-free 特征（近重复、数字覆盖、margin）均不能单调区分方向，9 例官方有害样本本身不可复现。下一步若要做 Gate，应先在官方可重建的 collection 上扩样，再用"线索局部性 vs 全局性"这类组合特征、且只在大分差（非抖动区）样本上评估。

## 附录 A：MR 决定性不一致的排查证据链

1. **管线语义**：官方 rerank 查 Qdrant 中索引阶段写入的多向量（`retrieval_rerank.py` filter_by_filenames，dense_limit=100，无 document_name 过滤）；embedder 代码（bf16、`process_images/process_queries`、pylate document_length=8192）与重放逐行一致。
2. **Qdrant 语义**：embedded Qdrant（cosine + MAX_SIM、exact）对 2899 全候选的排序与 numpy MaxSim 完全一致，分差 ~0.01（float32）；doc/query token 范数 0.997–1.003，显式归一化不改变排序；无量化、float32 存储。
3. **模型/权重**：LoRA 394 个张量全部非零且前向确实生效（逐层开关均值差 0.016/0.025，全模型开关 0.092）；适配器权重最后更新 2025-04-01、基座 colqwen2.5-7B-base 权重 2025-04-15 后未变，均早于官方实验（2026-08/09）；03-31/04-15 历史 commit 的 config/权重组合已验证（旧基座缺 custom_text_proj，投影层随机初始化，非官方有效模型）。
4. **数据**：8 数据集 parquet 内容自 2026-01/04 上传后未变（08-27 仅 YAML/引用元数据提交）；TATDQA 同 filename 多行图像像素 MD5 全部相同；重放存储向量与 HF 现取现编码**逐位相等**。
5. **软件版本**：transformers 4.50.0 vs 4.50.3、colpali-engine 0.3.9/0.3.10（0.3.11+ 与官方 <4.51 约束冲突）、pylate 1.5.0/1.5.1/1.6.0 下，2899/6875 重排分数**逐位一致**；image processor fast/slow 路径输出一致（fast 静默回退）。
6. **候选集**：tatdqa 全库 2,758 页 MR 重放中，10 个案例的 GT 名次与 Top-100 内重放一致（top 外部页分数均低于内部最高分），排除 dense 尾部丢页。
7. **反证对照**：TD 12/12 对齐、TR 全部决定性案例对齐，证明评测口径与晚交互实现无误——偏差特异于"已发布 ColNomic 模型在当前软件栈下的输出"与"官方入库向量"之间，而该 collection 状态无公开快照。
